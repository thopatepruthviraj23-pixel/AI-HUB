🤖 AI Hub Website

📌 Project Overview

AI Hub is a beginner-friendly website that provides a centralized platform to explore popular Artificial Intelligence tools and basic AI concepts. The website is designed with a clean and simple interface using HTML and CSS, making it easy to navigate and understand.

This project is ideal for students and beginners who want to learn about AI tools in one place.

---

🚀 Features

- 🏠 Home Page – Introduction to Artificial Intelligence
- 🧰 Tools Page – Information about popular AI tools like ChatGPT, Gemini, and GitHub Copilot
- ℹ️ About Page – Purpose and details about the website
- 📞 Contact Page – Basic contact form or details
- 🎨 Simple UI – Clean and responsive design
- ⚡ Lightweight – Fast loading website

---

🛠️ Technologies Used

- HTML5
- CSS3

🎯 Purpose of the Project

The main objective of AI Hub is:

- To provide information about AI tools in one place
- To help beginners understand Artificial Intelligence
- To serve as a microproject for students
